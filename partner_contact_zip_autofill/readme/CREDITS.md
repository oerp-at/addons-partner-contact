## Data sources

- **Austria:** postal-code table (Postleitzahlenverzeichnis) published as open
  data by [RTR](https://data.rtr.at/), sourced from the Austrian Post.
- **Germany:** street list from the
  [openPLZ data project](https://github.com/openpotato/openplzapi.data),
  derived from [OpenStreetMap](https://www.openstreetmap.org/). This data is
  licensed under the
  [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/) and
  is (c) OpenStreetMap contributors.
- **Tie-breaking:** the [OpenPLZ API](https://openplzapi.org/) is queried live
  to disambiguate postal codes that are shared by several cities.
